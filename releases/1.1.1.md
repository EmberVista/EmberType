# EmberType 1.1.1 (build 208) — Release Log

**Why:** licensing hardening. Activation now uses Polar's public license endpoints, a key is stored only after Polar accepts it, stored licenses are re-checked periodically, and the trial applies to every transcription path. Adds a remote minimum-build requirement (`embertype.com/app-config.json`, see `VoiceInk/Services/MinimumVersion.swift`). Removes the stale `EmberTalk 1.0.0` app that was bundled inside every build (the 1.0.2/1.1 follow-up), roughly halving the download.

- DevHarness unit tests 32/32 (new: LicenseRulesTests, MinimumVersionTests).

- Real Polar key (free test purchase): validate, activate ×3, 4th activation refused, unknown key/activation refused with a readable message. Test activations removed.
